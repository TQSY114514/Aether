核心特性

九大能力覆盖从日常对话到复杂工程任务

💬

多模型对话

会话中途无缝切换 OpenAI / Claude / DeepSeek / Ollama / LM Studio 等。支持 OpenAI 兼容与 Anthropic 原生两种协议。

Stable
🔧

Agent 工具循环

Plan→Act→Observe 循环，三层沙箱防御（工作区根、路径遍历防护、命令黑名单），五级权限门控。

Beta
🏟

多模型 Arena

多模型并发回答同一问题，用户投票选出最佳，ELO 排行榜实时更新。本地优先方案中独此一家。

Beta
🧩

技能与扩展

SKILL.md 指令系统 + MCP stdio 协议 + 10 点 Hook 生命周期。外部工具与内置工具透明合并。

Experimental
🧠

结构化记忆

跨会话保存用户偏好与项目决策。Agent 可主动调用 memory_save / memory_search 工具管理记忆。

Beta
📋

层级规划

复杂请求自动分解为并行子任务，委派给隔离子 Agent 执行（最多 5 个并发），结果自动汇总。

Experimental
📦

上下文压缩

长会话自动摘要，保留工具调用对与关键信息，节省 token 消耗。支持 Anthropic cache_control 断点。

Beta
🔒

本地优先隐私

全部数据存储在本地 SQLite 数据库。API Key、会话历史、Persona 配置永不上传，仅与 LLM Provider 通信。

Stable
🌍

15 种 UI 语言

含简繁中文、文言文、日语、韩语、英/西/法/德/葡/俄/乌/阿/印地语。支持 RTL 阿拉伯语布局。
