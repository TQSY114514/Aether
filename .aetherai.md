# Aether AI Workbench — Workspace Instructions (.aetherai.md)

You are working in the repository for **Aether**, a local-first, multi-model AI agent workbench.

## Core Rules for Agents
1. **Proactive Knowledge Base Logging (知识库主动沉淀)**:
   - Every time a significant feature is completed, a critical bug is fixed, or an architectural pattern/lesson is learned, **proactively record it into `D:\.知识库`**:
     - Create a detailed dev log in `D:\.知识库\03-开发日志/` (titled `YYYY-MM-DD-<topic>.md`)
     - Append numbered golden lessons to `D:\.知识库\04-踩坑与经验\Aether踩坑与经验.md`
     - Update navigation in `D:\.知识库\00-索引.md`
   - Do this proactively at the end of relevant tasks without waiting for user reminders.
2. **Directory Boundaries**:
   - `app/electron/` is Node.js CommonJS ONLY (`require`/`module.exports`). No `import`/`export`, no TS types (`: string`, `as X`).
   - `app/src/` is React 18 + TypeScript + Zustand + Tailwind.
   - `app/tui/` is React + Ink v5 terminal interface, strictly Electron-free.
3. **IPC Three-File Contract**:
   - Any IPC change requires updating: `ipc/*.handler.js`, `preload.js`, and `src/env.d.ts`.
4. **Database Rules**:
   - `better-sqlite3` WAL mode. All parameterized queries must use `prepare(...).get/all/run` with `?` placeholders.
   - Cast `lastInsertRowid` using `Number()` before returning or storing.
5. **UI Design Rules**:
   - Follow `docs/ui-design.md`. No purple/indigo background gradients, no `bg-clip-text` gradient headlines, no emoji icons (use Lucide).
   - Use the input-anchored `AgentActionHUD` and `AgentTaskDeck` patterns for agent visibility.
6. **Testing & Verification**:
   - `cd app && npm run build` (runs IPC check, TypeScript check, and Vite build) must pass before committing.
